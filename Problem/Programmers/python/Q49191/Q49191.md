# 49191 순위

## 문제 설명

n명의 선수와 경기 결과 results가 주어진다. 각 행 [A, B]는 A가 B를 이겼다는 뜻이다.
실력이 더 좋은 선수는 항상 이기며, 주어진 결과에는 모순이 없다.
정확한 순위를 알 수 있는 선수의 수를 반환한다.

## 제한사항

- 선수 수: 1 이상 100 이하
- 경기 결과 수: 1 이상 4,500 이하
- 선수 번호: 1부터 n까지

## 입출력 예

| n | results | return |
| --- | --- | --- |
| 5 | [[4, 3], [4, 2], [3, 2], [1, 2], [2, 5]] | 2 |

## 풀이: 플로이드 워셜

1. `wins[a][b]`에 a가 b를 이길 수 있는지를 저장한다.
2. 경유 선수 middle을 기준으로, a가 middle을 이기고 middle이 b를 이기면 a가 b도 이긴다고 기록한다. 경유 선수 반복문을 가장 바깥에 두어 간접적인 승패 관계를 모두 구한다.
3. 각 선수에 대해 자신이 이기는 선수와 자신을 이기는 선수의 총수가 n - 1이면 순위가 확정된다. 이때 순위는 자신을 이기는 선수 수 + 1이다.

아직 승패를 모르는 상대가 있으면 그 상대와의 앞뒤 순서를 결정할 수 없으므로 순위가 확정되지 않는다.

예시에서 2번은 1, 3, 4번에게 지고 5번에게 이겨 4위다. 5번은 나머지 모두에게 지므로 5위다. 따라서 답은 2다.

## 복잡도

- 시간: O(n³)
- 공간: O(n²)
