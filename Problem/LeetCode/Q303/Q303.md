# LeetCode 303번 - Range Sum Query - Immutable

[문제 보러 가기](https://leetcode.com/problems/range-sum-query-immutable/)

## 문제 요약

정수 배열 `nums`로 `NumArray` 객체를 초기화한다. `sumRange(left, right)`는 인덱스 `left`부터 `right`까지 양 끝을 포함한 원소의 합을 반환한다. 배열은 조회 중 변경되지 않는다.

## 예시

```python
numArray = NumArray([-2, 0, 3, -5, 2, -1])
numArray.sumRange(0, 2)  # 1
numArray.sumRange(2, 5)  # -1
numArray.sumRange(0, 5)  # -3
```

## 풀이

- `Python/Q303_v1.py`: 배열을 저장하고 조회마다 슬라이싱과 `sum()`으로 구간 합을 계산한다. 구간 길이가 k일 때 조회 시간과 임시 공간은 O(k)이다.
- `Python/Q303_v2.py`: `prefix[i]`에 앞의 i개 원소 합을 저장한다. `prefix[right + 1] - prefix[left]`로 구간 합을 계산한다. 초기화는 O(n) 시간·공간, 조회는 O(1) 시간이다.
